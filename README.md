# DäckFlow – webbapp

DäckFlow för iPhone (och alla telefoner): **LYFT** (skanna regnummer, plats i däckhotellet, kund, däck, ordrar) och **KUNDMOTTAGARE** (kö till verkstaden).

Öppna sidan i Safari → Dela → **Lägg till på hemskärmen**.

Kunddata finns bara i telefonen: filen CompleteStorageList.xlsx väljs i appen och läggs inte upp här.
